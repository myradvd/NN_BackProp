## NNbackprop-first-principles

This project is an independent implementation of a scalar-valued backpropagation engine, built off first principles from Andrej Karpathy's MicroGrad. It includes the re-derivation of automatic differentiation from a calculus and graph-theoretic foundation, with detailed explanations, numerical gradient verification against analytic results, and trained models.

It extends MicroGrad's idea and scope to mathematically explain, verify and visualise concepts like vanishing gradients, and allow for exploration and comparison of different optimisers like Adam, SGD, etc in thorough detail.

Note: To run the Try_Out ipynb file on VsCode, you need to have GraphViz installed (installers can be found here: https://graphviz.org/download/) and added onto your system PATH. Locate and replace the first code block in the file, to ensure you don't run into FileNotFound Errors.
